# Poporo Open Design Agent Skill

Use this skill when the user wants to:
1. Generate or redesign interactive 3D presentations of cultural heritage artifacts (Poporo Quimbaya).
2. Apply the `quimbaya-gold` design system (deep obsidian, burnished gold, sacred geometry).
3. Produce parametric CAD specs, JSON hardware manifests, and WebGL/Canvas interactive viewers.
4. Export and deliver responsive web deliverables with automated GitHub Actions CI/CD.

## Capabilities & Workflows
- **Visuals:** WebGL / Canvas 3D parametric rotational engine with Real Gold, Wireframe CAD, and X-Ray cross-sections.
- **Narrative:** Museum-grade curatorial breakdowns covering metallurgy, mambeo ritual, and Piece 00001 history.
- **Specs:** Standardized JSON schemas for Open Hardware and 3D printing (FDM/SLA).
- **Delivery:** Auto-deployable to GitHub Pages with standard linting workflows.
